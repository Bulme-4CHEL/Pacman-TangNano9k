# Pac-Man on TangNano (Custom Open-Source Toolchain Fork)

> **Note:** This repository is a **custom fork** of the original *Pac-Man on TangNano9K* project.
> The original work, design, and licensing remain fully credited to the original author.
> This fork adapts the project to work **standalone with an open-source FPGA toolchain**
> instead of the proprietary GoWin IDE.
>
> All original license terms apply unchanged. This fork only adds build/tooling documentation
> and minor integration changes.

---

## Open-Source Toolchain (Main Focus of This Fork)

This fork is intended to be built and programmed **entirely with open-source tools**
using **OSS-CAD-Suite** and the **Lushay VSCode extension**.

<details open>
<summary><strong>Install / Setup</strong></summary>

1. **Install the Lushay Extension in VSCode**
   - Open VSCode
   - Go to Extensions
   - Search for **“Lushay Code”**
   - Install it

2. **Install OSS-CAD-Suite**
   1. Download from:
      https://github.com/YosysHQ/oss-cad-suite-build/releases/
      → **Choose the Windows build**
   2. Extract it somewhere, for example:
      ```
      C:\_dev\oss-cad-suite
      ```
   3. In VSCode, open the Command Palette:
      ```
      Ctrl + Shift + P
      ```
   4. Select:
      ```
      Preferences: Open Settings (UI)
      ```
   5. Navigate to:
      ```
      Extensions → Lushay Code
      ```
   6. Find:
      ```
      Lushay.Oss Cad Suite: Path
      ```
   7. Paste the OSS-CAD-Suite path **and append `\bin`**, for example:
      ```
      C:\_dev\oss-cad-suite\bin
      ```

3. **Install the TangNano9K USB Driver**
   1. Plug in your **TangNano9K**
   2. Download and start **Zadig 2.9**:
      https://zadig.akeo.ie/
   3. In Zadig:
      - Go to **Options → List All Devices**
      - Select:
        ```
        JTAG Debugger (Interface 0)
        ```
        or sometimes:
        ```
        Sipeed-Debug (Interface 0)
        ```
      **Important:**
      - Use **Interface 0**, **NOT Interface 1**
      - Ensure the driver selected is on the right side is **WinUSB**
   4. Click **Replace Driver**

4. **Configure Lushay**
   - A `lushay.json` file already exists in this repository
   - Adjust it if needed for your local setup
   - (Configuration was generated with the help of an LLM and should work out-of-the-box)

</details>

# Pac-Man on TangNano9k

A Pac-Man Arcade implementation for the TangNano9K using HDMI for video and audio output.
See it in action in the Youtube Video.
The latest version supports the use of a USB Joystick.

![Pac-Man](images/pacman_hdmi_wide.jpeg)

## Why another Pac-Man in HDL?

There are many Pac-Man implementations in HDL, especially the great
version by MikeJ. I wanted to gain some experiences with the GoWin FPGAs
and wanted to make use of the HDMI output of the TangNano9K.

Most existing versions recreate the original video and output an upright
60 Hz NTSC-style signal intended for portrait-mounted screens.
Converting that to HDMI usually requires a separate frame buffer.

This implementation directly outputs a modern-compatible signal.
The video logic replaces the original arcade video system and outputs
a double-scanned signal with 576 lines (576p at 60 Hz).

By default, the video resolution is 1024x576 to fit a 16:9 screen.
The game area is centered with dark blue borders on the left and right.
A 4:3 mode (768x576) can be enabled by commenting out “define WIDE”
in src/top.sv.

## ROMs

Since this project implements the Pac-Man arcade hardware,
the original ROM files are required.

They can be obtained from the Pac-Man (Midway) ROM set.

The ROMs must be converted into HDL source files compatible with
the toolchain. This can be done using the provided Python conversion
tool and shell script in src/roms.
